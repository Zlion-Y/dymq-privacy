# dymq-privacy

「抖音画质锁 · Douyin Max Quality」浏览器扩展在 Microsoft Edge Add-ons 商店的隐私政策声明页。

- 线上地址：https://zlion-y.github.io/dymq-privacy/
- 用途：满足 Edge Add-ons 审核对「独立可访问的隐私政策 URL」的要求
- 内容：声明本扩展不收集、不存储、不传输任何用户数据，并说明 `storage` 与 `https://*.douyin.com/*` 两项权限的具体用途

源文件维护在扩展项目内（`douyin-max-quality/store/privacy-policy.html`），本仓库只存放部署副本。

本扩展为非官方工具，与抖音、字节跳动及其关联公司无隶属或合作关系。
